## 题目理解

给定一棵二叉树的根节点 `root`，判断它是否是**有效的二叉搜索树（BST）**。

BST 的定义：

- 左子树所有节点的值 **严格小于** 根节点的值
- 右子树所有节点的值 **严格大于** 根节点的值
- 左右子树也必须是 BST

例如：

```ts
// true
root = [2, 1, 3]

// false：根 5 的右子树里有 4，违反了「右子树全部大于 5」
root = [5, 1, 4, null, null, 3, 6]
```

注意是**严格**小于/大于，相等不算合法（例如 `[2, 2, 2]` 为 `false`）。

## 思路：DFS + 取值上下界

只比较「节点与直接子节点」不够：例如 `[5, 4, 6, null, null, 3, 7]` 中，根 `5` 与右孩子 `6` 满足大小关系，但 `6` 的左孩子 `3` 仍小于根 `5`，整棵树不是 BST。

正确做法是：从根往下 DFS 时，为每个节点携带它**允许落入的取值区间** `(min, max)`（开区间或闭区间均可，这里用开区间更直观）：

- 根节点允许 `(-∞, +∞)`
- 进入左子树：上界收紧为当前节点值，即 `(min, root.val)`
- 进入右子树：下界收紧为当前节点值，即 `(root.val, max)`

若某节点值不在 `(min, max)` 内，直接返回 `false`；左右子树都合法则当前子树合法。

中序遍历得到严格递增序列也能判 BST，但需要 O(n) 额外空间存遍历结果或显式栈；上下界 DFS 在平衡树上递归栈 O(h)，且逻辑与 BST 定义一一对应。

### 代码实现（TypeScript）

```ts
class TreeNode {
  val: number;
  left: TreeNode | null;
  right: TreeNode | null;
  constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
    this.val = val ?? 0;
    this.left = left ?? null;
    this.right = right ?? null;
  }
}

function isValidBST(root: TreeNode | null): boolean {
  return validate(root, -Infinity, Infinity);
}

function validate(
  node: TreeNode | null,
  min: number,
  max: number
): boolean {
  if (!node) return true;

  // Current value must sit strictly inside (min, max)
  if (node.val <= min || node.val >= max) return false;

  const leftOk = validate(node.left, min, node.val);
  const rightOk = validate(node.right, node.val, max);

  return leftOk && rightOk;
}
```

`min` / `max` 随递归向下传递，子树无法「绕回」祖先的约束，因此能覆盖整棵树的全局 BST 性质。
