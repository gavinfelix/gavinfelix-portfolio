## 题目理解

给定一个**不含重复元素**的整数数组 `nums`，返回该数组所有可能的子集（幂集）。

解集**不能**包含重复子集。

例如：

```ts
nums = [1, 2, 3]
// 返回 [[], [1], [2], [1, 2], [3], [1, 3], [2, 3], [1, 2, 3]]
```

空集 `[]` 也是合法答案之一。

## 思路：回溯

子集问题的本质是：对数组中每个元素，决定**选**或**不选**。

用回溯模板维护：

- `path`：当前正在构建的子集
- `start`：下一个可以尝试的元素下标，保证只向后搜索，避免 `[1,2]` 和 `[2,1]` 这种顺序不同但内容相同的重复

每一步有两种选择：

1. **不选** `nums[i]`：直接尝试 `i + 1`
2. **选** `nums[i]`：把 `nums[i]` 加入 `path`，递归 `i + 1`，回溯时 `pop`

更简洁的写法是：每到一层递归，先把当前 `path` 的副本加入答案（代表「到这一步为止的某个子集」），再枚举 `start` 之后的元素逐个尝试加入。

### 代码实现（TypeScript）

```ts
function subsets(nums: number[]): number[][] {
  const res: number[][] = [];
  const path: number[] = [];

  function backtrack(start: number) {
    res.push([...path]);

    for (let i = start; i < nums.length; i++) {
      path.push(nums[i]);
      backtrack(i + 1);
      path.pop();
    }
  }

  backtrack(0);
  return res;
}
```

`res.push([...path])` 放在循环外，这样每个递归深度都会记录一个合法子集，包括空集（`start = 0` 且 `path` 为空时最先被加入）。

## 另一种思路：位运算

数组长度为 `n`，每个元素对应二进制的一位：`0` 表示不选，`1` 表示选。从 `0` 到 `2^n - 1` 枚举所有 bitmask，就能生成全部 `2^n` 个子集。适合理解题意，但回溯更通用，也更容易扩展到「有重复元素」的 [LeetCode 90 - Subsets II](https://leetcode.com/problems/subsets-ii/)。
