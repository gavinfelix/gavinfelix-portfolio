## 题目理解

给定二维平面上 `n` 个点的坐标，其中 `points[i] = [xi, yi]`。

求**同一条直线**上最多能有多少个点（一条直线上的点计入同一组）。

例如：

```ts
points = [[1, 1], [2, 2], [3, 3]]
// 返回 3：三点共线

points = [[1, 1], [3, 2], [5, 3], [4, 1], [2, 3], [1, 4]]
// 返回 4：没有一条直线穿过全部 6 个点，最多 4 点共线
```

两点确定一条直线；当多个点两两斜率相同且过同一点时，它们共线。浮点数直接比较斜率会因精度出问题，本题宜用**有理斜率**（约分后的 `dy/dx`）或等价表示做哈希键。

## 思路：锚点 + 斜率哈希

暴力是枚举所有点三元组，复杂度太高。标准做法是：**固定一个锚点** `points[i]`，统计与其共线的其它点中有多少落在同一条方向上。

对固定的 `i`，遍历 `j > i`：

1. **重合点**：`dx === 0 && dy === 0`，与 `i` 位置相同，记 `same`，可与任意斜率上的点叠在同一直线上；
2. **竖线**：`dx === 0` 且 `dy !== 0`，斜率无穷，用固定键 `'vertical'`；
3. **一般斜率**：用 `gcd(|dy|, |dx|)` 约分得到 `(ndy, ndx)`，再统一符号（例如令 `ndx > 0`，或 `ndx === 0` 时令 `ndy > 0`），转成字符串键如 `"dy/dx"`，在 `Map` 中累加经过 `i` 且与 `j` 同方向的点数。

这一轮中，经过锚点 `i` 的某条直线上最多点数为 `same + maxCount`（`maxCount` 为某一斜率方向上的点数，不含锚点自身重复计数的那一份时要看实现：常见写法是 `same` 含锚点，`maxCount` 只计 `j` 方向）。取所有锚点的最大值即为答案。

可选剪枝：若剩余未当作锚点的个数 `n - i` 已经不超过当前答案 `ans`，后面不可能更优，可 `break`。

### 代码实现（TypeScript）

```ts
function gcd(a: number, b: number): number {
  a = Math.abs(a);
  b = Math.abs(b);
  while (b !== 0) {
    const t = a % b;
    a = b;
    b = t;
  }
  return a;
}

function slopeKey(dx: number, dy: number): string {
  if (dx === 0) return 'vertical';
  const g = gcd(dy, dx);
  let ndy = dy / g;
  let ndx = dx / g;
  // Normalize sign so each direction has one representation
  if (ndx < 0 || (ndx === 0 && ndy < 0)) {
    ndy = -ndy;
    ndx = -ndx;
  }
  return `${ndy}/${ndx}`;
}

function maxPoints(points: number[][]): number {
  const n = points.length;
  if (n <= 2) return n;

  let ans = 0;

  for (let i = 0; i < n; i++) {
    if (n - i <= ans) break;

    const slopes = new Map<string, number>();
    let same = 1;
    let maxOnLine = 0;

    for (let j = i + 1; j < n; j++) {
      const dx = points[j][0] - points[i][0];
      const dy = points[j][1] - points[i][1];

      if (dx === 0 && dy === 0) {
        same++;
        continue;
      }

      const key = slopeKey(dx, dy);
      const count = (slopes.get(key) ?? 0) + 1;
      slopes.set(key, count);
      maxOnLine = Math.max(maxOnLine, count);
    }

    ans = Math.max(ans, same + maxOnLine);
  }

  return ans;
}
```

当所有点都与锚点重合时，`maxOnLine` 为 0，答案由 `same` 反映（`n` 个相同坐标）。当只有竖线方向有点时，`'vertical'` 桶与 `same` 合并计数方式与普通斜率一致。
