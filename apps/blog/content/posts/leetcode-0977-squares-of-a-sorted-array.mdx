## 题目理解

给定一个按**非递减顺序**排列的整数数组 `nums`，返回一个同样按非递减顺序排列的新数组，其中每个元素是 `nums` 中对应元素的平方。

例如：

```ts
nums = [-4, -1, 0, 3, 10]
// 返回 [0, 1, 9, 16, 100]
```

数组里可能有负数，平方后最大值不一定在右端（例如 `-4` 的平方比 `3` 更大）。

## 思路：双指针从两端向中间

如果先对每个数平方再排序，复杂度是 O(n log n)。

观察：原数组已经有序，**绝对值最大的数只可能出现在两端**——要么是最左边的负数，要么是最右边的正数。

因此可以用双指针：

- `left` 指向开头，`right` 指向末尾
- 比较 `nums[left]²` 和 `nums[right]²`，把较大的平方写入结果数组的尾部
- 移动对应指针，继续比较，直到 `left > right`

结果从后往前填，自然得到升序。

### 代码实现（TypeScript）

```ts
function sortedSquares(nums: number[]): number[] {
  const n = nums.length;
  const result = new Array<number>(n);
  let left = 0;
  let right = n - 1;
  let write = n - 1;

  while (left <= right) {
    const leftSq = nums[left] * nums[left];
    const rightSq = nums[right] * nums[right];

    if (leftSq > rightSq) {
      result[write] = leftSq;
      left++;
    } else {
      result[write] = rightSq;
      right--;
    }
    write--;
  }

  return result;
}
```

全为非负数时，相当于每次取 `right` 一侧；全为负数时，相当于每次取 `left` 一侧。同一套逻辑都能覆盖。
