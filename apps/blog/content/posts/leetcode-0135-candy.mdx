## 题目理解

`n` 个孩子站成一排，每人有一个评分 `ratings[i]`。

你要分糖果，规则如下：

- 每个孩子至少 `1` 颗糖
- 相邻两个孩子中，评分更高的那个分到的糖**必须更多**

返回满足条件时，最少需要多少颗糖。

例如：

```ts
ratings = [1, 0, 2]
// 返回 5：分法之一为 [2, 1, 2]

ratings = [1, 2, 2]
// 返回 4：分法之一为 [1, 2, 1]
```

## 思路：贪心两次扫描

只盯「比左边高」或「比右边高」的一侧不够：例如 `[1, 3, 2, 2]`，从左扫会得到 `[1, 2, 1, 1]`，但中间孩子评分 `3` 高于右边 `2`，还需再多一颗。

做法分两步：

1. **从左到右**：若 `ratings[i] > ratings[i - 1]`，则 `candy[i] = candy[i - 1] + 1`，否则 `candy[i] = 1`。这样每个孩子相对**左邻**已满足要求。
2. **从右到左**：若 `ratings[i] > ratings[i + 1]`，则 `candy[i] = max(candy[i], candy[i + 1] + 1)`。在保留左扫结果的同时，补齐相对**右邻**的约束。

最终 `candy` 每个位置取左右两次扫描的较大值，累加即为答案。两次都是线性贪心，不需要回溯或动态规划表。

### 代码实现（TypeScript）

```ts
function candy(ratings: number[]): number {
  const n = ratings.length;
  const candies = new Array<number>(n).fill(1);

  // Left to right: higher rating than left neighbor gets one more candy
  for (let i = 1; i < n; i++) {
    if (ratings[i] > ratings[i - 1]) {
      candies[i] = candies[i - 1] + 1;
    }
  }

  // Right to left: enforce the right-neighbor rule without undoing the left pass
  for (let i = n - 2; i >= 0; i--) {
    if (ratings[i] > ratings[i + 1]) {
      candies[i] = Math.max(candies[i], candies[i + 1] + 1);
    }
  }

  return candies.reduce((sum, c) => sum + c, 0);
}
```

左扫、右扫各处理一侧邻居，与 [LeetCode 134 Gas Station](/posts/leetcode-0134-gas-station) 一样用**单向贪心扫描**消掉不可能状态；这里第二次扫描用 `max` 合并两侧约束，而不是从零重算。
