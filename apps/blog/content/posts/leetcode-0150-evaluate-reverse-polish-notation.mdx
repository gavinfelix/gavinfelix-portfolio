## 题目理解

给定一个字符串数组 `tokens`，表示一个**逆波兰表达式**（后缀表达式）。

每个元素要么是整数，要么是 `+`、`-`、`*`、`/` 之一。

求这个表达式的值。除法向零截断（truncate toward zero）。

例如：

```ts
tokens = ["2", "1", "+", "3", "*"]
```

等价于 `(2 + 1) * 3`，结果是 `9`。

另一个例子：

```ts
tokens = ["4", "13", "5", "/", "+"]
```

先算 `13 / 5 = 2`，再算 `4 + 2 = 6`。

## 思路：栈

后缀表达式的特点是：运算符出现在它需要的两个操作数**之后**。

从左到右扫描 `tokens`：

- 如果是数字，压入栈
- 如果是运算符，从栈顶弹出两个数作为右操作数和左操作数（注意顺序），计算后再压回栈

扫描结束后，栈里只剩一个数，就是答案。

### 代码实现（TypeScript）

```ts
function evalRPN(tokens: string[]): number {
  const stack: number[] = [];

  for (const token of tokens) {
    if (token === "+" || token === "-" || token === "*" || token === "/") {
      const right = stack.pop()!;
      const left = stack.pop()!;
      let value = 0;

      if (token === "+") {
        value = left + right;
      } else if (token === "-") {
        value = left - right;
      } else if (token === "*") {
        value = left * right;
      } else {
        value = Math.trunc(left / right);
      }

      stack.push(value);
    } else {
      stack.push(Number(token));
    }
  }

  return stack[0];
}
```
