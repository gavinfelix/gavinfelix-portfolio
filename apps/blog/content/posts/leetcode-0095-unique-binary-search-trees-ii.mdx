## 题目理解

给定整数 `n`，生成所有由节点值 `1` 到 `n` 组成的、**结构不同**的二叉搜索树（BST），并返回每棵树的根节点。

BST 性质：左子树所有节点值小于根，右子树所有节点值大于根；左右子树本身也必须是 BST。

例如：

```ts
n = 3
// 返回 5 棵树的根（与 LeetCode 96 的五种结构一一对应）：

//   1         3     3      2      1
//    \       /     /      / \      \
//     3     1     1      1  3      2
//    /       \     \           \
//   2         2     2           3
```

`n = 1` 时只返回一棵单节点树。

与 [LeetCode 96 - Unique Binary Search Trees](/posts/leetcode-0096-unique-binary-search-trees) 的区别：

- 96：只统计 BST 的**个数**（卡特兰数）
- 95：要**构造并返回**每一棵不同的 BST

## 思路：分治 + 回溯构造

对区间 `[start, end]` 内的所有 BST：

1. 枚举根节点值 `rootVal`（`start ≤ rootVal ≤ end`）
2. 递归得到左子树集合 `build(start, rootVal - 1)` 与右子树集合 `build(rootVal + 1, end)`
3. 将每一对 `(left, right)` 挂到新根 `rootVal` 下，加入当前区间的答案

边界：当 `start > end` 时，对应**空子树**，返回 `[null]`，这样非空根也能与「只有一侧有子树」的情况正确组合。

外层调用 `build(1, n)` 即可。

### 代码实现（TypeScript）

```ts
class TreeNode {
  val: number;
  left: TreeNode | null;
  right: TreeNode | null;
  constructor(val?: number, left?: TreeNode | null, right?: TreeNode | null) {
    this.val = val === undefined ? 0 : val;
    this.left = left === undefined ? null : left;
    this.right = right === undefined ? null : right;
  }
}

function generateTrees(n: number): Array<TreeNode | null> {
  if (n === 0) return [];

  function build(start: number, end: number): Array<TreeNode | null> {
    if (start > end) return [null];

    const trees: Array<TreeNode | null> = [];

    for (let rootVal = start; rootVal <= end; rootVal++) {
      const leftTrees = build(start, rootVal - 1);
      const rightTrees = build(rootVal + 1, end);

      for (const left of leftTrees) {
        for (const right of rightTrees) {
          const root = new TreeNode(rootVal);
          root.left = left;
          root.right = right;
          trees.push(root);
        }
      }
    }

    return trees;
  }

  return build(1, n);
}
```

`build` 对同一区间可能被不同根重复调用；若需要优化，可用 `Map` 记忆化 `(start, end)` 的子树列表，本题 `n` 较小时直接递归即可。

## 复杂度分析

答案共有 `G(n)` 棵 BST（`G(n)` 为卡特兰数）。构造每棵树要分配 `O(n)` 个节点，输出总规模约为 `O(n × G(n))`。

不计结果集时，递归深度为 `O(n)`，每层临时列表与调用栈占用 `O(n)` 量级空间。
