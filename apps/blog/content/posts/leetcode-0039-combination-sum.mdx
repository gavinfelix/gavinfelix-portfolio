## 题目理解

给定一个**无重复元素**的正整数数组 `candidates` 和一个目标整数 `target`，找出 `candidates` 中所有可以使数字和为 `target` 的组合。

`candidates` 中的**同一个数字可以无限制重复被选取**。如果至少一种组合的和等于 `target`，返回这些组合；否则返回空数组。

解集**不能**包含重复的组合（例如 `[2, 2, 3]` 与 `[2, 3, 2]` 视为同一组合）。

例如：

```ts
candidates = [2, 3, 6, 7], target = 7
// 返回 [[2, 2, 3], [7]]

candidates = [2, 3, 5], target = 8
// 返回 [[2, 2, 2, 2], [2, 3, 3], [3, 5]]

candidates = [2], target = 1
// 返回 []
```

## 思路：回溯 + start 控制顺序

与 [LeetCode 216 - Combination Sum III](/posts/leetcode-0216-combination-sum-iii) 类似，用回溯枚举组合，但本题允许**重复使用**同一数字。

维护：

- `path`：当前组合
- `sum`：当前组合和
- `start`：下一个可选数字的下标，只向后搜索，保证组合按非递减顺序生成，避免 `[2, 3, 2]` 与 `[2, 2, 3]` 这类重复

每一步从 `start` 开始尝试 `candidates[i]`：

1. 若 `sum + candidates[i] > target`，后面的数只会更大，直接 `break` 剪枝
2. 把 `candidates[i]` 加入 `path`，递归时 **`start` 仍为 `i`**（同一数字可再次选用），而不是 `i + 1`
3. 回溯时 `pop` 恢复状态

当 `sum === target` 时，把 `path` 的副本加入答案。

### 代码实现（TypeScript）

```ts
function combinationSum(candidates: number[], target: number): number[][] {
  const res: number[][] = [];
  const path: number[] = [];

  function backtrack(start: number, sum: number) {
    if (sum === target) {
      res.push([...path]);
      return;
    }

    for (let i = start; i < candidates.length; i++) {
      if (sum + candidates[i] > target) break;

      path.push(candidates[i]);
      backtrack(i, sum + candidates[i]);
      path.pop();
    }
  }

  backtrack(0, 0);
  return res;
}
```

`backtrack(i, ...)` 而不是 `backtrack(i + 1, ...)` 是本题与 Combination Sum III 的核心区别：前者表示「当前数字还可以再选一次」，后者表示「每个数字最多用一次」。

## 复杂度分析

最坏情况下需要枚举所有合法组合；每个组合拷贝进结果最多 O(target / min(candidates))。不计结果集时，`path` 与递归栈深度最多 O(target / min(candidates))。
