## 题目理解

给定无向连通图里某个节点的引用，返回该图的**深拷贝**。

每个节点包含整型 `val` 和邻居列表 `neighbors`：

```ts
class Node {
  val: number;
  neighbors: Node[];
  constructor(val?: number, neighbors?: Node[]) {
    this.val = val ?? 0;
    this.neighbors = neighbors ?? [];
  }
}
```

深拷贝需要新建节点对象，并把邻居关系按原图一一对应连好，不能与原图共享任何 `Node` 实例。

例如，`adjList = [[2, 4], [1, 3], [2, 4], [1, 3]]` 表示 1 连 2、4，2 连 1、3，以此类推；克隆后应得到结构相同、对象全新的一套节点。

## 思路：BFS + 哈希表映射

若只复制节点值而不处理「同一邻居被多条边引用」，会出现重复节点或遗漏边。标准做法是维护 `Map<原节点, 克隆节点>`：

1. 从入参节点入队；若图中尚未为其建克隆，则 `new Node(val)` 并写入 map
2. 出队一个原节点时，取其克隆副本，遍历原节点的每个邻居
3. 邻居若尚未在 map 中，先创建克隆并入队，保证每个原节点只被复制一次
4. 把邻居对应的克隆节点 `push` 到当前克隆的 `neighbors` 里

BFS 保证按层扩展，与 [LeetCode 102 Binary Tree Level Order Traversal](/posts/leetcode-0102-binary-tree-level-order-traversal) 类似，但这里复制的是**图**且边可能形成环，map 用来判重并复用已克隆的邻居。

DFS + 递归同样可行：先 `clone(node)`，再递归克隆每个未访问邻居并挂到 `neighbors`；下文给出 BFS 写法，面试里两种都常考。

### 代码实现（TypeScript）

```ts
class Node {
  val: number;
  neighbors: Node[];
  constructor(val?: number, neighbors?: Node[]) {
    this.val = val ?? 0;
    this.neighbors = neighbors ?? [];
  }
}

function cloneGraph(node: Node | null): Node | null {
  if (node === null) return null;

  const cloned = new Map<Node, Node>();
  const queue: Node[] = [node];

  // Seed the map with the start node before BFS
  cloned.set(node, new Node(node.val));

  while (queue.length > 0) {
    const current = queue.shift()!;
    const copy = cloned.get(current)!;

    for (const neighbor of current.neighbors) {
      if (!cloned.has(neighbor)) {
        cloned.set(neighbor, new Node(neighbor.val));
        queue.push(neighbor);
      }
      copy.neighbors.push(cloned.get(neighbor)!);
    }
  }

  return cloned.get(node)!;
}
```

`cloned.has(neighbor)` 为真时只追加已有克隆，不再入队，避免环上重复 BFS。
