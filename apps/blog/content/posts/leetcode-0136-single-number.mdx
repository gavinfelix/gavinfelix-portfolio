## 题目理解

给定一个非空整数数组 `nums`，除了一个元素只出现一次以外，其余每个元素都出现两次。找出那个只出现一次的元素。

要求：线性时间复杂度，并且只使用常数额外空间。

例如：

```ts
nums = [2, 2, 1]       // 返回 1
nums = [4, 1, 2, 1, 2] // 返回 4
```

## 思路：异或

哈希表能做，但需要 O(n) 额外空间，不满足常数空间要求。

异或（`^`）有三个关键性质：

1. `a ^ a = 0`（自己和自己异或得 0）
2. `a ^ 0 = a`（和 0 异或不变）
3. 异或满足交换律和结合律（顺序无所谓）

把数组里所有数依次异或：成对出现的数字会两两抵消成 `0`，最后剩下的就是那个只出现一次的数。

例如 `[4, 1, 2, 1, 2]`：

```ts
0 ^ 4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4 ^ 0 ^ 0
= 4
```

### 代码实现（TypeScript）

```ts
function singleNumber(nums: number[]): number {
  let result = 0;

  for (const num of nums) {
    result ^= num;
  }

  return result;
}
```

一行写法也可以：`nums.reduce((a, b) => a ^ b, 0)`。
