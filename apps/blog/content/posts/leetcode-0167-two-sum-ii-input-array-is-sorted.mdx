## 题目理解

给定一个 **下标从 1 开始** 计数的 **升序** 整数数组 `numbers` 和整数 `target`。

在数组中找出两个数，使它们的和等于 `target`。

返回这两个数的下标（长度 2 的数组，且 **1-based**）。

保证恰好只有一组解，且同一元素不能使用两次。

例如：

```ts
numbers = [2, 7, 11, 15], target = 9
// 2 + 7 = 9，返回 [1, 2]

numbers = [2, 3, 4], target = 6
// 返回 [1, 3]
```

与 [LeetCode 1 Two Sum](/posts/leetcode-0001-two-sum) 相比：本题数组有序、返回 1-based 下标，且通常要求 O(1) 额外空间（哈希表仍可做，但双指针更贴题意）。

## 思路：左右双指针

升序下，固定左端 `numbers[left]` 时，右端越大，和越大。

维护 `left = 0`、`right = numbers.length - 1`，每次比较 `sum = numbers[left] + numbers[right]` 与 `target`：

- `sum === target`：找到答案，返回 `[left + 1, right + 1]`（转成 1-based）
- `sum < target`：和太小，左指针右移，尝试更大的左端值
- `sum > target`：和太大，右指针左移

每个指针最多移动 n 次，整体 O(n)。有序性保证了不会漏解：若当前和小于 target，则对固定 `left`，任何更小的 `right` 和只会更小，因此可以安全地 `left++`。

### 代码实现（TypeScript）

```ts
function twoSum(numbers: number[], target: number): number[] {
  let left = 0;
  let right = numbers.length - 1;

  while (left < right) {
    const sum = numbers[left] + numbers[right];

    if (sum === target) {
      // Problem uses 1-based indices
      return [left + 1, right + 1];
    }

    if (sum < target) {
      left++;
    } else {
      right--;
    }
  }

  return [];
}
```

题目保证有解，循环内一定会命中 `sum === target`；最后的 `return []` 仅为满足类型检查。

也可以用二分在 `numbers[left + 1 .. right]` 中查找 `target - numbers[left]`，单次 O(n log n)；双指针一次扫描更简洁，与 [LeetCode 11 Container With Most Water](/posts/leetcode-0011-container-with-most-water) 的夹逼套路同源。
