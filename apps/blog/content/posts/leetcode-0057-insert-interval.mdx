## 题目理解

给定一个按**起点升序**排列、且**互不重叠**的区间数组 `intervals`，以及一个新区间 `newInterval = [start, end]`。

把 `newInterval` 插入 `intervals`，使结果仍按起点升序，且任意两个区间不重叠（若与已有区间重叠，需要合并）。

例如：

```ts
intervals = [[1, 3], [6, 9]]
newInterval = [2, 5]
// 输出: [[1, 5], [6, 9]]
// [2,5] 与 [1,3] 重叠，合并为 [1,5]

intervals = [[1, 2], [3, 5], [6, 7], [8, 10], [12, 16]]
newInterval = [4, 8]
// 输出: [[1, 2], [3, 10], [12, 16]]
// [4,8] 与 [3,5]、[6,7]、[8,10] 都重叠，合并为 [3,10]
```

## 思路：线性扫描 + 三段合并

和 [LeetCode 56 Merge Intervals](/posts/leetcode-0056-merge-intervals) 类似，区间题可以排序后贪心处理。本题输入已经有序且无重叠，不必整体重排，只需**一遍扫描**分三段：

1. **左侧**：所有在 `newInterval` 之前结束的区间（`interval[i][1] < newInterval[0]`），直接加入结果
2. **中间**：所有与 `newInterval` 重叠的区间（`interval[i][0] <= newInterval[1]`），不断把 `newInterval` 的左右端点扩展为合并后的范围
3. **右侧**：把合并后的 `newInterval` 放入结果，再把剩余区间依次加入

重叠判断和合并规则与 Merge Intervals 一致：当前区间起点 `<= newInterval` 的右端点即视为重叠；合并时左端点取 `Math.min`，右端点取 `Math.max`。

### 代码实现（TypeScript）

```ts
function insert(intervals: number[][], newInterval: number[]): number[][] {
  const result: number[][] = [];
  let i = 0;
  const n = intervals.length;

  // Intervals that end before newInterval starts
  while (i < n && intervals[i][1] < newInterval[0]) {
    result.push(intervals[i]);
    i++;
  }

  // Merge overlapping intervals into newInterval
  while (i < n && intervals[i][0] <= newInterval[1]) {
    newInterval[0] = Math.min(newInterval[0], intervals[i][0]);
    newInterval[1] = Math.max(newInterval[1], intervals[i][1]);
    i++;
  }
  result.push(newInterval);

  // Remaining intervals after the merged block
  while (i < n) {
    result.push(intervals[i]);
    i++;
  }

  return result;
}
```

直接修改 `newInterval` 数组作为合并中的临时区间，避免额外变量；`result` 最多容纳 `n + 1` 个区间（合并后可能变少）。
