## 题目理解

给定一个未排序的整数数组 `nums`，返回其中**最长连续序列**的长度。

要求算法的时间复杂度为 O(n)。

例如：

```ts
nums = [100, 4, 200, 1, 3, 2] // 返回 4，最长连续序列是 [1, 2, 3, 4]
nums = [0, 3, 7, 2, 5, 8, 4, 6, 0, 1] // 返回 9
nums = [] // 返回 0
```

本题不能先排序再扫描——排序是 O(n log n)。核心是利用哈希集合在 O(1) 时间内判断某个数是否存在，从而在线性时间内找出所有连续段。

## 思路：哈希集合 + 只从序列起点扩展

先把所有数字放进 `Set`，方便 O(1) 判断 `num - 1`、`num + 1` 是否存在。

遍历 `Set` 中的每个 `num`：

- 若 `num - 1` 也在集合中，说明 `num` 不是连续段的起点，跳过（避免重复计数）
- 若 `num - 1` 不存在，则从 `num` 向右不断检查 `num + 1`、`num + 2` … 直到断开，得到以 `num` 开头的连续段长度
- 用 `maxLen` 记录全局最大值

关键优化：每个数字最多作为「起点」被扩展一次、作为「中间元素」被跳过一次，总工作量仍是 O(n)。

与 [LeetCode 217 Contains Duplicate](/posts/leetcode-0217-contains-duplicate) 一样依赖 `Set` 做 O(1) 查找；与 [LeetCode 560 Subarray Sum Equals K](/posts/leetcode-0560-subarray-sum-equals-k) 不同，本题不需要前缀和，而是利用数值的连续性在集合上「走链」。

### 代码实现（TypeScript）

```ts
function longestConsecutive(nums: number[]): number {
  const numSet = new Set(nums);
  let maxLen = 0;

  for (const num of numSet) {
    // Only expand from the start of a consecutive sequence
    if (!numSet.has(num - 1)) {
      let current = num;
      let length = 1;

      while (numSet.has(current + 1)) {
        current++;
        length++;
      }

      maxLen = Math.max(maxLen, length);
    }
  }

  return maxLen;
}
```

`num - 1` 存在时直接 `continue` 等价于内层 `if` 的否定分支，保证每段连续序列只从最小元素出发计数一次。

## 复杂度分析

建 `Set` 遍历数组一次；每个元素最多被外层访问一次、内层 `while` 扩展时最多再访问一次。
