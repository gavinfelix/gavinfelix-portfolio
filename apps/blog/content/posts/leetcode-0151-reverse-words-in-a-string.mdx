## 题目理解

给定一个字符串 `s`，其中单词由非空格字符组成，单词之间至少有一个空格分隔。

要求**反转单词的顺序**，并用**单个空格**把单词拼接成结果字符串。输入可能含有**首尾空格**或**单词间多个空格**，返回结果不应保留这些多余空格。

例如：

```ts
s = "the sky is blue"
// 返回 "blue is sky the"

s = "  hello world  "
// 返回 "world hello"

s = "a good   example"
// 返回 "example good a"
```

## 思路：整体反转 + 逐词反转

要把单词顺序倒过来，经典做法是**在字符数组上**分三步（多次对区间做双指针交换，与原地反转字符串的思路相同）：

1. **去掉首尾空格，并把中间连续空格压成一个**（双指针 `read` / `write` 扫一遍，或先 `trim` 再规范间距；下面实现用一次线性扫描写出紧凑数组）
2. **反转整个字符数组**
3. **对每个单词区间分别反转**，此时单词顺序即为所求

若用 TypeScript 的 `string`，可先 `split('')` 得到可变数组，最后在有效长度处 `join('')`。

另一种写法是 `trim` 后按 `\s+` 分割再 `reverse().join(' ')`，代码更短，但本题更强调**原地**字符操作与双指针，与链表、数组原地题一脉相承。

### 代码实现（TypeScript）

```ts
function reverseRange(chars: string[], left: number, right: number): void {
  while (left < right) {
    const tmp = chars[left];
    chars[left] = chars[right];
    chars[right] = tmp;
    left++;
    right--;
  }
}

function reverseWords(s: string): string {
  const chars = s.split('');
  const n = chars.length;
  let write = 0;

  // Collapse spaces: skip leading/multiple spaces, keep one space between words
  for (let read = 0; read < n; read++) {
    if (chars[read] === ' ') {
      if (write === 0 || chars[write - 1] === ' ') continue;
    }
    chars[write++] = chars[read];
  }
  // Trim trailing space if present
  if (write > 0 && chars[write - 1] === ' ') write--;

  const len = write;
  if (len === 0) return '';

  reverseRange(chars, 0, len - 1);

  let start = 0;
  for (let i = 0; i <= len; i++) {
    if (i === len || chars[i] === ' ') {
      reverseRange(chars, start, i - 1);
      start = i + 1;
    }
  }

  return chars.slice(0, len).join('');
}
```

第一步后 `len` 为规范化后的长度；全串反转后单词边界仍由空格分隔，再对每个单词做小范围反转即可恢复字母顺序并得到全局逆序。
