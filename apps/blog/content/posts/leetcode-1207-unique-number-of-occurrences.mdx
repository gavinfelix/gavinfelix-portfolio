## 题目理解

给定一个整数数组 `arr`，判断数组中每个数字的出现次数是否都不相同。

如果任意两个不同数字的出现次数相同，返回 `false`；否则返回 `true`。

例如：

```ts
arr = [1, 2, 2, 1, 1, 3]
```

其中：

- `1` 出现 `3` 次
- `2` 出现 `2` 次
- `3` 出现 `1` 次

出现次数分别是 `3`、`2`、`1`，没有重复，所以返回 `true`。

## 思路：哈希表计数 + Set 去重

这题可以分成两步：

1. 用 `Map` 统计每个数字出现了多少次
2. 用 `Set` 判断这些出现次数是否重复

如果某个出现次数已经在 `Set` 中出现过，说明有两个数字的出现次数相同，直接返回 `false`。

遍历结束后还没有重复，返回 `true`。

### 代码实现（TypeScript）

```ts
function uniqueOccurrences(arr: number[]): boolean {
  const countMap = new Map<number, number>();

  for (const num of arr) {
    countMap.set(num, (countMap.get(num) ?? 0) + 1);
  }

  const seenCounts = new Set<number>();

  for (const count of countMap.values()) {
    if (seenCounts.has(count)) {
      return false;
    }

    seenCounts.add(count);
  }

  return true;
}
```
