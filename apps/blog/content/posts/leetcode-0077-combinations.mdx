## 题目理解

给定两个整数 `n` 和 `k`，返回从 `[1, n]` 中选出 `k` 个数的所有可能组合。

可以按任意顺序返回答案。

例如：

```ts
n = 4, k = 2
// 返回 [[1, 2], [1, 3], [1, 4], [2, 3], [2, 4], [3, 4]]

n = 1, k = 1
// 返回 [[1]]
```

和 [LeetCode 78 - Subsets](/posts/leetcode-0078-subsets) 的区别：

- 78：子集长度可以是 0 到 n 任意值
- 77：组合长度**必须恰好为 k**

和 [LeetCode 216 - Combination Sum III](/posts/leetcode-0216-combination-sum-iii) 的区别：

- 216：还要满足选出的 k 个数之和等于 `n`
- 77：只要求从 `[1, n]` 中选 k 个数，没有目标和约束

## 思路：回溯

用 `path` 记录当前组合，用 `start` 控制下一层只能从更大的数开始尝试，保证组合按递增顺序生成，从而避免 `[1, 2]` 与 `[2, 1]` 这类重复。

回溯过程：

1. 若 `path.length === k`，说明凑满 k 个数，把 `[...path]` 加入答案
2. 否则从 `start` 到 `n` 枚举下一个候选数 `i`
3. 选中 `i`：`path.push(i)`，递归 `backtrack(i + 1)`，回溯时 `path.pop()`

剪枝：当前还需要 `need = k - path.length` 个数，而从 `i` 到 `n` 最多还有 `n - i + 1` 个候选。若 `n - i + 1 < need`，后面再怎么选也凑不满 k 个，直接 `break`。

### 代码实现（TypeScript）

```ts
function combine(n: number, k: number): number[][] {
  const res: number[][] = [];
  const path: number[] = [];

  function backtrack(start: number) {
    if (path.length === k) {
      res.push([...path]);
      return;
    }

    const need = k - path.length;

    for (let i = start; i <= n; i++) {
      // Not enough numbers left in [i, n] to fill the combination
      if (n - i + 1 < need) break;

      path.push(i);
      backtrack(i + 1);
      path.pop();
    }
  }

  backtrack(1);
  return res;
}
```

`backtrack(i + 1)` 表示当前数 `i` 已使用，下一层只能从 `i + 1` 开始，这与子集、组合类回溯的通用模板一致。

## 复杂度分析

共有 C(n, k) 种组合，每种拷贝进结果最多 O(k)。回溯树深度为 k，不计结果集时 `path` 与递归栈空间为 O(k)。
