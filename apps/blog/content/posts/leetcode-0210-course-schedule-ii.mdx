## 题目理解

共有 `numCourses` 门课，编号 `0` 到 `numCourses - 1`。数组 `prerequisites` 中每一项 `[a, b]` 表示：要学课程 `a`，必须先学课程 `b`。

返回一个合法的上课顺序，使你能学完所有课程。如果不存在这样的顺序（先修图有环），返回**空数组**。

例如：

```ts
numCourses = 2, prerequisites = [[1, 0]]
// 返回 [0, 1]

numCourses = 4, prerequisites = [[1, 0], [2, 0], [3, 1], [3, 2]]
// 返回 [0, 2, 1, 3] 或 [0, 1, 2, 3] 等任一合法拓扑序

numCourses = 1, prerequisites = []
// 返回 [0]
```

与 [LeetCode 207 Course Schedule](/posts/leetcode-0207-course-schedule) 的区别在于：207 只判断能否学完，本题在能学完时还要**输出一种拓扑序**。

## 思路：Kahn 算法（BFS 拓扑排序）

把先修关系建成有向边 `b -> a`（学完 `b` 才能学 `a`），并统计每门课的**入度**。

1. 将所有入度为 `0` 的课放入队列（这些课没有未完成的先修）
2. 从队列头取出课程 `u`，加入结果数组
3. 对 `u` 的每条出边 `u -> v`，将 `v` 的入度减 `1`；若减后 `v` 入度为 `0`，入队
4. 重复 2–3 直到队列为空
5. 若结果数组长度等于 `numCourses`，说明无环，返回结果；否则有环，返回 `[]`

每次只选入度为 0 的课，保证选出的课的先修都已排在前面；若图中无环，最终会处理全部节点。

也可以用 DFS 后序逆序得到拓扑序，与 207 的三色 DFS 写法衔接；本题用 Kahn 更直观地「一层层剥」入度。

### 代码实现（TypeScript）

```ts
function findOrder(
  numCourses: number,
  prerequisites: number[][]
): number[] {
  const graph: number[][] = Array.from({ length: numCourses }, () => []);
  const indegree = new Array<number>(numCourses).fill(0);

  for (const [course, prereq] of prerequisites) {
    graph[prereq].push(course);
    indegree[course]++;
  }

  const queue: number[] = [];
  for (let i = 0; i < numCourses; i++) {
    if (indegree[i] === 0) queue.push(i);
  }

  const order: number[] = [];

  while (queue.length > 0) {
    const node = queue.shift()!;
    order.push(node);

    for (const next of graph[node]) {
      indegree[next]--;
      if (indegree[next] === 0) queue.push(next);
    }
  }

  return order.length === numCourses ? order : [];
}
```

若希望队列操作为 O(1)，可把 `shift` 换成头指针索引；对面试规模的数据，上述写法足够清晰。

## 与 DFS 写法的关系

DFS 在检测到回边时可直接判定无解；在无环时对每个节点做后序收集，再反转数组即得一拓扑序。两种方法时间同为 O(V + E)，可按个人习惯选择。
