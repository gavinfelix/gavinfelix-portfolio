## 题目理解

给定两个升序链表的头节点 `list1` 和 `list2`，把它们合并成一个升序链表并返回头节点。

例如：

```ts
list1 = 1 -> 2 -> 4
list2 = 1 -> 3 -> 4
```

合并后：

```ts
1 -> 1 -> 2 -> 3 -> 4 -> 4
```

两个链表可能为空，也可能其中一个为空。

## 思路：哑节点 + 双指针

和 [LeetCode 206 Reverse Linked List](/posts/leetcode-0206-reverse-linked-list) 一样，链表题里用**哑节点**（dummy head）能省掉「第一个节点特殊处理」的分支。

维护一个 `curr` 指针，始终指向结果链表的尾部：

- 比较 `list1` 和 `list2` 当前节点的值，把较小的接到 `curr.next`
- 被选中的那条链表前进一步
- `curr` 也前进一步

当其中一条链表走完后，另一条剩下的节点已经有序，直接接到尾部即可。

### 代码实现（TypeScript）

```ts
function mergeTwoLists(
  list1: ListNode | null,
  list2: ListNode | null
): ListNode | null {
  const dummy = new ListNode(0);
  let curr = dummy;

  while (list1 !== null && list2 !== null) {
    if (list1.val <= list2.val) {
      curr.next = list1;
      list1 = list1.next;
    } else {
      curr.next = list2;
      list2 = list2.next;
    }
    curr = curr.next;
  }

  curr.next = list1 ?? list2;
  return dummy.next;
}
```

`list1.val <= list2.val` 用 `<=` 而不是 `<`，保证值相等时优先取 `list1`，结果稳定。

## 递归写法

也可以递归：每次比较两个头节点，把较小的那个的 `next` 指向递归合并的结果。

```ts
function mergeTwoLists(
  list1: ListNode | null,
  list2: ListNode | null
): ListNode | null {
  if (list1 === null) return list2;
  if (list2 === null) return list1;

  if (list1.val <= list2.val) {
    list1.next = mergeTwoLists(list1.next, list2);
    return list1;
  }

  list2.next = mergeTwoLists(list1, list2.next);
  return list2;
}
```

递归写法更短，但空间是 O(n)。面试里一般优先写迭代 + 哑节点版本。
