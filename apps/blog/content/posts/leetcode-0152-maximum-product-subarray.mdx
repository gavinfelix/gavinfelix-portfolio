## 题目理解

给定一个整数数组 `nums`，找出**乘积最大的连续子数组**（至少包含一个元素），返回该乘积。数组元素可正可负，也可含 `0`。

例如：

```ts
nums = [2, 3, -2, 4]
// 子数组 [2, 3] 乘积为 6

nums = [-2, 0, -1]
// 子数组 [-2] 或 [-1]，乘积为 2 或 1，最大为 2

nums = [-2, 3, -4]
// 子数组 [-2, 3, -4] 乘积为 24
```

与「最大子数组和」（LeetCode 53）类似，但乘法里**负数乘以负数会变成很大的正数**，只跟踪最大乘积不够，还要记住当前最小乘积。

## 思路：滚动维护 max / min 乘积

遍历到下标 `i` 时，定义：

- `maxProd`：以 `nums[i]` **结尾**的子数组的最大乘积
- `minProd`：以 `nums[i]` **结尾**的子数组的最小乘积（可能为负，后面碰到负数时才有机会「翻身」）

若只考虑接在前面或从 `nums[i]` 重新开始，递推本是：

```ts
maxProd = Math.max(nums[i], maxProd * nums[i]);
minProd = Math.min(nums[i], minProd * nums[i]);
```

但当 `nums[i] < 0` 时，原来的 `minProd * nums[i]` 可能变成新的 `maxProd`，原来的 `maxProd * nums[i]` 可能变成新的 `minProd`。因此在更新前先**交换** `maxProd` 与 `minProd`（仅当当前数为负），再套用上面的式子。

全局答案 `result` 取每一步的 `maxProd` 的最大值。

### 代码实现（TypeScript）

```ts
function maxProduct(nums: number[]): number {
  let maxProd = nums[0];
  let minProd = nums[0];
  let result = nums[0];

  for (let i = 1; i < nums.length; i++) {
    if (nums[i] < 0) {
      // Negative flip: smallest ending product becomes largest after multiply
      [maxProd, minProd] = [minProd, maxProd];
    }

    maxProd = Math.max(nums[i], maxProd * nums[i]);
    minProd = Math.min(nums[i], minProd * nums[i]);
    result = Math.max(result, maxProd);
  }

  return result;
}
```

也可以不显式交换，而对三个候选值取最值：

```ts
const x = nums[i];
const a = x;
const b = maxProd * x;
const c = minProd * x;
maxProd = Math.max(a, b, c);
minProd = Math.min(a, b, c);
```

两种写法等价，都是 **O(n)** 时间、**O(1)** 额外空间。
