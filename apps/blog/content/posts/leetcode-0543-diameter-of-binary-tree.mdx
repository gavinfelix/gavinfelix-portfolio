## 题目理解

给定一棵二叉树的根节点 `root`，返回这棵树的**直径**。

直径定义为：树中任意两个节点之间最长路径上的**边数**。这条路径不一定经过根节点。

例如：

```ts
     1
   /   \
  2     3
 / \
4   5
```

最长路径是 `4 → 2 → 1 → 3` 或 `5 → 2 → 1 → 3`，共 3 条边，返回 `3`。

单节点树直径为 `0`。

## 思路：后序 DFS，在节点处「拼」路径

对任意节点 `node`，若一条路径**经过** `node` 且在该点拐弯（一端在左子树、一端在右子树），则这条路径的边数等于：

`左子树高度 + 右子树高度`

（这里的高度指从该子树根到最远叶子的**边数**，空子树高度为 `0`。）

整棵树的直径，就是所有节点上上述值的最大值。

一次后序遍历即可同时完成两件事：

1. 递归得到左右子树高度
2. 用 `left + right` 更新全局最大直径
3. 向父节点返回 `max(left, right) + 1` 作为以 `node` 为根的子树高度

与 [LeetCode 104 - Maximum Depth of Binary Tree](/posts/leetcode-0104-maximum-depth-of-binary-tree) 类似，都是后序合并左右子树信息；本题在合并时多维护一个「经过当前节点的最长路径」。

### 代码实现（TypeScript）

```ts
function diameterOfBinaryTree(root: TreeNode | null): number {
  let maxDiameter = 0;

  function depth(node: TreeNode | null): number {
    if (node === null) return 0;

    const left = depth(node.left);
    const right = depth(node.right);

    maxDiameter = Math.max(maxDiameter, left + right);

    return Math.max(left, right) + 1;
  }

  depth(root);
  return maxDiameter;
}
```

`maxDiameter` 用闭包或类成员保存即可，避免把直径当作递归返回值与高度混淆。

## 常见误区

- 把直径当成**节点数**（应为边数）：例如只有两个节点的链，直径是 `1` 而不是 `2`。
- 只比较「经过根」的路径：直径可能完全落在某一侧子树里，因此必须在**每个**节点都尝试 `left + right`。
