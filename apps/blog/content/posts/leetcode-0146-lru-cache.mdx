## 题目理解

设计并实现 **LRU（Least Recently Used）缓存**，支持：

- `LRUCache(capacity)` 以正整数 `capacity` 作为容量初始化
- `get(key)`：若 `key` 存在则返回对应 `value`，否则返回 `-1`
- `put(key, value)`：若 `key` 已存在则更新 `value`；否则插入。容量满时淘汰**最久未使用**的项

`get`、`put` 均须在 **O(1)** 时间复杂度内完成。

例如 `capacity = 2`：

```ts
const cache = new LRUCache(2);
cache.put(1, 1); // cache: {1=1}
cache.put(2, 2); // cache: {1=1, 2=2}
cache.get(1);    // 返回 1，1 变为最近使用
cache.put(3, 3); // 淘汰 key 2，cache: {1=1, 3=3}
cache.get(2);    // 返回 -1（2 已被淘汰）
cache.put(4, 4); // 淘汰 key 1，cache: {4=4, 3=3}
cache.get(1);    // 返回 -1
cache.get(3);    // 返回 3
cache.get(4);    // 返回 4
```

## 思路：哈希表 + 双向链表

只靠哈希表无法 O(1) 知道「谁最久没用」；只靠链表无法 O(1) 按 key 查找。

组合方式：

1. **`Map<key, 节点>`**：按 key 直接找到链表里的节点。
2. **双向链表（头最近、尾最旧）**：在头部表示刚刚访问/插入；容量溢出时删掉**紧挨尾哨兵**的节点即为 LRU。

配合两个哑节点 `head`、`tail`，插入与删除不用判空边界。核心操作：

- **移到头部**：`get` 命中或 `put` 更新时，先把节点从链表摘掉，再插到 `head` 后。
- **插入新键**：新节点插到头部；若 `map.size > capacity`，摘掉尾部 LRU，并从 `map` 删掉其 `key`（节点上需存 `key`，否则删 map 时不知道删哪个）。

与 [LeetCode 0138 Copy List with Random Pointer](/posts/leetcode-0138-copy-list-with-random-pointer) 一样用「指针结构 + 辅助结构」满足 O(1) 定位；这里链表顺序表达时间，map 表达 key 索引。

### 代码实现（TypeScript）

```ts
class DLinkedNode {
  key: number;
  value: number;
  prev: DLinkedNode | null;
  next: DLinkedNode | null;

  constructor(key = 0, value = 0) {
    this.key = key;
    this.value = value;
    this.prev = null;
    this.next = null;
  }
}

class LRUCache {
  private capacity: number;
  private cache: Map<number, DLinkedNode>;
  private head: DLinkedNode;
  private tail: DLinkedNode;

  constructor(capacity: number) {
    this.capacity = capacity;
    this.cache = new Map();
    this.head = new DLinkedNode();
    this.tail = new DLinkedNode();
    this.head.next = this.tail;
    this.tail.prev = this.head;
  }

  private removeNode(node: DLinkedNode): void {
    const prev = node.prev!;
    const next = node.next!;
    prev.next = next;
    next.prev = prev;
  }

  private addToHead(node: DLinkedNode): void {
    node.prev = this.head;
    node.next = this.head.next;
    this.head.next!.prev = node;
    this.head.next = node;
  }

  private moveToHead(node: DLinkedNode): void {
    this.removeNode(node);
    this.addToHead(node);
  }

  private popTail(): DLinkedNode {
    const node = this.tail.prev!;
    this.removeNode(node);
    return node;
  }

  get(key: number): number {
    if (!this.cache.has(key)) return -1;
    const node = this.cache.get(key)!;
    this.moveToHead(node);
    return node.value;
  }

  put(key: number, value: number): void {
    if (this.cache.has(key)) {
      const node = this.cache.get(key)!;
      node.value = value;
      this.moveToHead(node);
      return;
    }

    const node = new DLinkedNode(key, value);
    this.cache.set(key, node);
    this.addToHead(node);

    if (this.cache.size > this.capacity) {
      const lru = this.popTail();
      this.cache.delete(lru.key);
    }
  }
}
```

每个节点记录 `key`，淘汰尾部时才能从 `map` 里删掉对应项；`get`、`put` 的命中路径都只是常数次指针改写。
