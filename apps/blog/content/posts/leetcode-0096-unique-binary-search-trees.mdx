## 题目理解

给定一个整数 `n`，求由 `1` 到 `n` 为节点值组成的**结构不同**的二叉搜索树（BST）一共有多少种。

BST 性质：左子树所有节点值小于根，右子树所有节点值大于根；左右子树本身也必须是 BST。

例如：

```ts
n = 3
// 返回 5

// 五种结构（节点值均为 1、2、3）：
//   1         3     3      2      1
//    \       /     /      / \      \
//     3     1     1      1  3      2
//    /       \     \           \
//   2         2     2           3
```

`n = 1` 时只有一种树。

## 思路：区间动态规划（卡特兰数）

对节点集合 `{1, 2, …, n}`，任选 `j`（`1 ≤ j ≤ n`）作为根：

- 左子树只能由 `{1, …, j - 1}` 构成，方案数为 `G(j - 1)`
- 右子树只能由 `{j + 1, …, n}` 构成，方案数为 `G(n - j)`

以 `j` 为根时，总方案数为 `G(j - 1) × G(n - j)`。对所有根 `j` 求和：

```ts
G(n) = Σ G(j - 1) × G(n - j)   (j = 1 .. n)
```

边界：`G(0) = 1`（空树算一种结构），`G(1) = 1`。

令 `dp[i]` 表示 `i` 个节点时的 BST 种数，则：

```ts
dp[0] = 1
dp[i] = Σ dp[j - 1] × dp[i - j]   (j = 1 .. i)
```

这与卡特兰数一致；`n` 较小时直接 O(n²) 填表即可。

### 代码实现（TypeScript）

```ts
function numTrees(n: number): number {
  // dp[i] = number of structurally unique BSTs with nodes 1..i
  const dp = new Array<number>(n + 1).fill(0);
  dp[0] = 1;
  dp[1] = 1;

  for (let nodes = 2; nodes <= n; nodes++) {
    for (let root = 1; root <= nodes; root++) {
      const leftCount = root - 1;
      const rightCount = nodes - root;
      dp[nodes] += dp[leftCount] * dp[rightCount];
    }
  }

  return dp[n];
}
```

外层 `nodes` 从小到大计算，内层枚举根 `root`；`dp[leftCount]` 与 `dp[rightCount]` 在更新 `dp[nodes]` 时已经就绪。

## 复杂度分析

共有 `n` 个状态，每个状态枚举至多 `n` 个根，转移为 O(1)。
